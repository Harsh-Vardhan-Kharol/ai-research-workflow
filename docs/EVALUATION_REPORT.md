# Phase 12 Evaluation Report

Generated by `PYTHONPATH=. python scripts/evaluate.py`. Machine-readable
results are in [`data/evaluation/evaluation_results.json`](../data/evaluation/evaluation_results.json).
The runner uses no network connection and no paid AI provider.

## Dataset and references

The controlled dataset contains ten synthetic papers and twenty short pages.
It varies title/metadata cues, heading forms, methods, datasets, metrics,
limitations, future work, omitted information, and includes one benign
prompt-injection string. Independent expected values and evidence quotes are
stored in `data/evaluation/annotations.json`. The annotations cover 140
paper-field pairs across the extraction schema fields. The papers and
annotations are compact, human-authored test material.

Extraction and evidence measures remain “Not measured” because the mock
provider intentionally emits unknown values and is not representative of the
AI extraction task. The optional `--predictions` input scores separately
produced predictions against the independent annotations. It distinguishes
EXACT_MATCH, NORMALIZED_MATCH, PARTIAL_MATCH, MISSING, INCORRECT,
UNAVAILABLE, and NOT_APPLICABLE. Only exact and normalized item matches count
as true positives. Evidence matching checks quoted text and page, not claim
entailment.

Confidence score levels and review routes were checked against six controlled
inputs. These are deterministic software checks, not a calibration study or
probability estimate. Comparison and gap values above measure agreement with
controlled expected outputs only; they are not estimates of behavior on
external literature.

## Reliability cases

Regression tests cover corrupt, empty, duplicate, invalid-MIME and oversized
PDFs; provider unavailability, timeout, bounded retry and malformed output;
schema-invalid extraction; invalid/unavailable evidence; database write
failure; invalid and duplicate review transitions; comparison selection
errors; and unknown paper, extraction, pattern and gap-candidate references.
The failure paths return safe errors or persisted failure states rather than a
successful invented result. Existing partial-processing and retry semantics
are tested without adding new retry behavior.

```bash
PYTHONPATH=. .venv/bin/python -m pytest -q

git diff --check
```

The result file records a generation timestamp. Regeneration updates that
timestamp. Pytest is the software regression suite and is reported separately
from empirical extraction metrics.

## Limitations

- Ten synthetic papers are too few and too controlled to generalize to the
  diversity or quality of published research.
- There is no live-provider extraction benchmark in the default offline run.
- Reference annotation choices can be subjective, especially for paraphrased
  claims and evidence relevance.
- Matching uses lexical normalization and a simple token-overlap partial
  category; it does not assess semantic equivalence or entailment.
- No significance testing or confidence calibration is attempted.
- Automated UI coverage is limited; Streamlit browser rendering remains a
  manual smoke test.
